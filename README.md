# shop-e2e-automation

Playwright Test framework for the LambdaTest OpenCart playground. The project uses JavaScript ES modules, matching the existing Playwright config and starter spec.

## Prerequisites

- Node.js 20 or newer
- npm
- Playwright's Chromium browser (`npx playwright install chromium`)

Install locked dependencies with `npm ci`. The GitHub Actions workflow pins Node.js `24.21.0`; the Playwright dependency supports Node.js 20 and newer.

## Configuration

`BASE_URL` optionally overrides the target origin. It defaults to `https://ecommerce-playground.lambdatest.io`; for example, set `$env:BASE_URL = 'https://example.test'` in PowerShell before running tests. The configuration uses a 30-second test timeout, 5-second assertion timeout, Chromium, and HTML reporting. CI uses one retry and one worker; local runs use no retries and two workers.

The repository ignores `.env` files, `node_modules`, `test-results`, and generated Playwright reports. The current UI suite requires no credentials or authenticated session.

## Commands

| Command | Purpose | Current status |
|---|---|---|
| `npm test` | Run all discovered Playwright tests | Runs the existing starter tests and the implemented UI tests |
| `npm run test:ui` | Run UI specs in `tests/ui/` | Runs homepage, search, product, cart, safe authentication, and checkout cases (12 tests currently) |
| `npm run test:api` | Run Playwright specs in `tests/api/` | Existing placeholder only; no API specs exist, and this command does not run Postman |
| `npm run test:headed` | Run all discovered tests in a visible browser | Uses the all-tests discovery scope |
| `npm run test:debug` | Run all discovered tests in Playwright debug mode | Uses the all-tests discovery scope |
| `npm run report` | Open the most recent HTML report | Requires a report generated by a prior run |

The original starter spec still checks `playwright.dev`; it is retained separately as starter coverage and is not an application test. The first application tests use page objects in `pages/` and cover the homepage, product search, and product details.

## GitHub Actions

The existing `.github/workflows/playwright.yml` runs on pushes and pull requests targeting `main` or `master`. Its single UI regression job uses Node.js `24.21.0`, installs dependencies with `npm ci`, installs Chromium, and runs `npx playwright test tests/ui --workers=1`. This executes the e-commerce UI specs under `tests/ui/` once; the retained `playwright.dev` starter tests are excluded from that job.

Open the repository's **Actions** tab and select a workflow run to review its job logs and status. From the run summary, download the `playwright-report` artifact for the HTML report and `playwright-test-results` for failure screenshots, traces, and other Playwright output. Both artifacts are retained for 30 days when the run is not cancelled.

Reproduce the UI job locally with:

```sh
npm ci
npx playwright install --with-deps chromium
npx playwright test tests/ui --workers=1
```

The LambdaTest storefront is the UI target. A separate local practice API would be a different target with its own server, contract, data, and Postman collection. This repository currently has no `api-server/`, verified storefront REST API, or configured Postman collection, so the workflow has no API job. The existing `npm run test:api` remains a Playwright placeholder and does not run Postman. The Echo learning exercise is not backend coverage. See [docs/api-test-plan.md](docs/api-test-plan.md) for the API gate and next steps.
